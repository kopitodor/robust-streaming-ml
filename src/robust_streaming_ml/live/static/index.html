Live keyword-spotting demo

Closed-set demo: not general speech recognition, and not production software. The model knows only the 10 commands below. Every 1 s window, including silence, noise, and other words, is assigned one of them. There is no silence or unknown-word rejection.

Audio goes only to this local server (127.0.0.1). It is processed in memory and never leaves this computer or reaches the disk.

    • Capture. After you press Start and allow the microphone, the browser captures raw audio at its own sample rate (echo cancellation, noise suppression, and automatic gain are requested off). It averages the channels to mono and sends 100 ms chunks, in order, to this local server.
